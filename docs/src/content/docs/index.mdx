```sh
rox up container -- my-agent --model example
```

`rox` clones your project's remote branch into a fresh guest and runs its `.rox.sh` setup hook, or starts from a project image that has already run it. It then creates a Rex session rooted at the checkout. The guest keeps running after the CLI exits, so you or an agent can reach it with `rex -S NAME`.

<CardGrid>
	<Card title="Containers or VMs" icon="laptop">
		Use Docker or Podman for ordinary Linux work. Use [Tart](guides/tart-vms/) on Apple Silicon when the work needs macOS or a full Linux VM.
	</Card>
	<Card title="Fast cold starts" icon="rocket">
		[Project images](guides/project-images/) run `.rox.sh` once at build time, so launching several workers takes seconds.

	<Card title="Built for agents" icon="puzzle">
